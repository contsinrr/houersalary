# 打工人时薪测算

一款帮助打工人计算真实时薪的PC端网页应用，考虑工作时长、通勤、加班、隐形支出等因素。

## 功能特性

- **收入计算**：输入月薪、年终奖、五险一金缴纳比例
- **时间成本**：设置工作时长、通勤时间、加班情况
- **隐形支出**：记录通勤费用、工作餐、职业相关支出
- **真实时薪计算**：综合考虑收入、时间和支出
- **数据可视化**：图表展示收入构成、时间分配、时薪对比
- **行业对比**：与互联网、金融等多个行业的平均时薪对比
- **本地存储**：自动保存数据，支持刷新后恢复
- **结果分享**：复制结果或保存测算报告

## 运行项目

```bash
# 安装依赖
npm install

# 启动开发服务器
npm run dev

# 构建生产版本
npm run build
```

访问 http://localhost:5173 查看应用。

## 使用说明

1. **填写收入信息** - 月薪、年终奖、五险一金比例
2. **设置时间成本** - 每日工作时长、通勤时间、加班情况
3. **添加支出** - 通勤、餐费及其他工作相关支出
4. **查看结果** - 获取真实时薪、行业对比和详细分析
